Origin-Destination (OD) Cost Matrix: Employees Served by Public Transit

Opprinnelse-destinasjon (OD) kostnadsmatrise: Ansatte betjent av offentlig transport

Project Overview

Prosjektoversikt

The study analyzed how many employees can be reached within 25 minutes by public transit during the morning rush hour, specifically on a Wednesday at 07:30. The analysis involved using public transit network data, population grid points, and Origin-Destination Cost Matrix analysis.

The results show the number of grid points with access to employees within the specified timeframe, aiding in understanding public transit effectiveness for commuting.

Studien analyserte kor mange tilsette som kan nåes innen 25 minutter med offentlig transport i morgonrushet, spesifikt på ein onsdag klokka 07:30. Analysen involverte bruk av data frå offentleg transportnettverk, befolkningsnettpunkt og Origin-Destination Cost Matrix-analyse.

Resultata viser talet på rutenettpunkt med tilgang til tilsette innanfor den spesifiserte tidsramma, og bidrar til å forstå effektiviteten av offentleg transport for pendling.
