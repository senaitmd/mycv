Senait Dawede

Service area coverage by public transit network from three sample location

Tjenesteområdedekning med offentlig transportnettverk fra tre utvalgssteder

Project Overview

Prosjektoversikt

In this section of Exercise 3, the public transit network dataset, employees_100 grid from the PT network dataset, Pop_gridpoints2019_250 from Trondheim_region.gdb, and service area analysis were used to calculate and compare the number of inhabitants and employees that can be reached from the sample facilities by public transit within 30 minutes for two different times of the day. [cite: 1239, 1240, 1241, 1242, 1243, 1244, 1245, 1246, 1247, 1248, 1249, 1250, 1251, 1252]

The analysis was made using service area network analysis on March 20, 2023, between 8:00 a.m. and 8:00 p.m., with a 30-minute cutoff and the public transit time set as a cost impedance. [cite: 1240, 1241, 1242, 1243, 1244, 1245, 1246, 1247, 1248, 1249, 1250, 1251, 1252]

The results included total area coverage within the specified cutoff and time, the total number of inhabitants, and the total number of employees. [cite: 1240, 1241, 1242, 1243, 1244, 1245, 1246, 1247, 1248, 1249, 1250, 1251, 1252]
