Exercise 3: Transit Network Analysis - Part 2b

This section of Exercise 3 focuses on calculating and comparing the number of inhabitants and employees that can be reached within 30 minutes for two different starting times using the public transit network dataset. [cite: 357, 358]

Methodology

The public transit network dataset, employees_100 grid, Pop_gridpoints2019_250, and service area analysis were used. Three-point feature classes (City Lade, City Syd Kjpesenter, and NTNU Dragvoll) were imported to the facility layer. The analysis was made using service area network analysis on March 20, 2023, at 8:00 a.m. and 8:00 p.m., with a 30-minute cutoff and public transit time set as a cost impedance. [cite: 358, 359, 360, 361]

The results included total area coverage within the specified cutoff and time, the total number of inhabitants, and the total number of employees. [cite: 361, 362, 363, 364, 365, 366, 367]
