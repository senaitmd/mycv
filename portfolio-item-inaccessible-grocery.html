Exercise 5 - Raster modeling pedestrian accessibility

Exercise Overview

In this exercise, pedestrian accessibility maps are created using the raster method of path distance. The exercise is done to identify areas that don't have access to the five groceries within 8 minutes for average adults in the sample area.

Data and Tools

Different data is used, which includes Cost_rast, Mask, Grocery/Food Shops, Hraster, and Resistance.txt. ArcGIS Pro tools, including the path distance spatial analysis tool and buffer analysis tool, were used.

Analysis Process

The different datasets are used as input. The default value of Resistance.txt is used to assign slope and speed to the sample area. The amount of travel time for an average adult citizen with the speed demanded to access certain facilities was calculated using the path distance spatial analysis tool. Buffer analysis tools were also used for adjusting datasets.

Key Findings

The areas impossible to access for average adult citizens are delineated. Some places couldn't access the groceries because pedestrians took longer to cross the road with traffic or were not allowed to cross, so they were forced to use a longer path to access them.
